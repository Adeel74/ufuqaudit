     4→Build **UfuqAudit** — an AI-Powered Website Audit SaaS for SEO, AEO, GEO & Technical Performance.

     9→## Architecture (high level)
    10→- Frontend: Next.js 16 App Router, TypeScript, Tailwind 4, shadcn/ui, Recharts, Zustand
    11→- Backend: Next.js API routes (use server not server actions)
    12→- DB: Prisma + SQLite
    13→- AI: z-ai-web-dev-sdk (LLM) — backend only
    14→- Single route `/` with client-side view switching
