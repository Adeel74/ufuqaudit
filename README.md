# UfuqAudit — AI-Powered Website Audit SaaS

> Find what's wrong. Understand why. Get the fix.

AI-powered website audit platform covering **SEO + AEO + GEO + Performance + Security** with 200+ checks, AI-generated fixes, and a 26-tab Super Admin Portal.

## 🚀 Quick Start

```bash
# Install dependencies
bun install

# Set up database
bun run db:push

# Start development server
bun run dev

# Open http://localhost:3000
```

## ✨ Features

### User Dashboard (35+ Views)
- **Audit Engine** — Real crawler with 200+ SEO checks across 6 engines
- **Visual Preview** — Page screenshots with SEO issue overlays
- **AI Recommendations** — Copy-paste ready fixes generated by LLM
- **AI Chat** — Conversational assistant grounded in audit context
- **UfuqLink** — Single-page link scanner + Chrome Extension
- **Competitor Comparison** — Side-by-side scoring with auto-find
- **Keyword Tracker** — SERP positions with sparklines + donut chart
- **Backlink Monitor** — Incoming links with DA distribution
- **Content Analyzer** — Readability (Flesch) + keyword density
- **Link Graph** — Interactive SVG node-edge visualization
- **Page Editor** — Edit meta tags with live SERP preview
- **Scheduled Audits** — Recurring audit scheduler
- **Client Portal** — Shareable branded audit links
- **Search Console** — GSC-style data dashboard
- **Email Reports** — Compose + send branded reports
- **PDF Export** — Print-to-PDF with white-label branding
- **All Audits** — Complete audit history with filters
- **Complete Report** — Single-page full audit summary

### Super Admin Portal (26 Tabs)
**Phase 1 (Core):** Dashboard · Users · Organizations · Plans · Subscriptions · Billing · API Keys · Audits · System
**Phase 2 (Product):** Audit Rules · Scoring · AI Models · AI Costs · Crawler
**Phase 3 (Growth):** Blog · Campaigns · Leads · Coupons · Affiliates · Announcements
**Phase 4 (Enterprise):** Feature Flags · Webhooks · Analytics · White Label · Competitors · Security

### Auth System
- Register / Login / Logout with session management
- RBAC with 6 roles: super_admin, admin, manager, editor, developer, user
- Password hashing (scrypt), session tokens (7-day expiry)
- Protected routes + admin-only access

### Chrome Extension (UfuqLink)
- Manifest V3 (Chrome) + Manifest V2 (Firefox)
- Content scanner: extracts links, SEO metadata, images
- Popup UI: scan → loading → results with animated score
- Service worker: HTTP status checking via fetch
- CSV export, notifications, UfuqAudit escalation

### Public Pages
- Landing (hero + free audit + features + pricing)
- Pricing (4 plans with comparison)
- Documentation (9 sections, 20+ pages with search)
- Features (18 feature cards)
- About + Blog

## 📦 Production Deployment

1. Copy `.env.example` to `.env` and configure:
   - `DATABASE_URL` — your production database
   - `NEXT_PUBLIC_APP_URL` — your domain
   - `AUTH_SECRET` — a secure random string
   - `ZAI_API_KEY` — your AI API key (optional)

2. Build and start:
```bash
bun run build:prod
bun run start:prod
```

3. For Vercel deployment:
```bash
vercel --prod
```
